# Bundled console fonts

Unmodified JetBrains Mono v2.304, from the official JetBrains/JetBrainsMono
repository, pinned to commit `cd5227bd1f61dff3bbd6c814ceaf7ffd95e947d9`.

Upstream source directory:
https://github.com/JetBrains/JetBrainsMono/tree/cd5227bd1f61dff3bbd6c814ceaf7ffd95e947d9/fonts/ttf

Bundled faces: `JetBrainsMono-Regular.ttf`, `JetBrainsMono-Bold.ttf`,
`JetBrainsMono-Italic.ttf`, and `JetBrainsMono-BoldItalic.ttf`.
Each file was downloaded from the corresponding path under:
https://raw.githubusercontent.com/JetBrains/JetBrainsMono/cd5227bd1f61dff3bbd6c814ceaf7ffd95e947d9/fonts/ttf/

https://raw.githubusercontent.com/JetBrains/JetBrainsMono/cd5227bd1f61dff3bbd6c814ceaf7ffd95e947d9/OFL.txt

These assets are compiled into the native application with `include_bytes!`.
No runtime download or system installation is needed.
